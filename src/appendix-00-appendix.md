## এপেন্ডিক্স

এখানে এনভায়রনমেন্ট সেটআপ, কমপ্লিট কোড লিস্টিং এবং গ্লসারি দেওয়া হলো।

এই বই জুড়ে আমরা অনেক কোড লিখেছি, অনেক tool ব্যবহার করেছি, আর অনেক technical term শিখেছি। এই এপেন্ডিক্স হলো একটি quick reference guide — যখন দরকার হবে তখন এখান থেকে দ্রুত information পাবে। পুরো বই আর flip করতে হবে না!

### কী কী আছে এপেন্ডিক্স এ?

- **এনভায়রনমেন্ট সেটআপ:** Conda environment তৈরি, Google Colab setup, local GPU configuration — শুরু থেকে শেষ পর্যন্ত complete installation guide। বই শুরু করার আগে environment prepare করতে এই section follow করো।

- **কমপ্লিট কোড লিস্টিং:** বই এর সবচেয়ে important functions ও models এর complete code — `simple_conv()`, LeNet-5, AlexNet, এবং Transfer Learning pipeline। Copy-paste ready code — experiment করার জন্য সরাসরি ব্যবহার করো।

- **গ্লসারি:** 30+ important technical terms এর Bengali definition — Activation Function থেকে VGG16 পর্যন্ত। Quick reference হিসেবে ব্যবহার করো যখন কোনো term মনে করতে হবে।

এই এপেন্ডিক্স বই এর content এর substitute নয় — বরং supplement। বই পড়ার সময় যে concepts শিখেছো, সেগুলো reference হিসেবে এখানে পাবে। বিশেষ করে নতুন environment তে project setup করতে গেলে বা interview এ preparation করতে গেলে এই এপেন্ডিক্স খুব কাজে লাগবে। তাই bookmark করে রাখো!
