## Glossary

This glossary provides English definitions of important technical terms in computer vision and deep learning. Use it as a quick reference while reading the book.

| Term | Definition |
|------|-----------|
| **Activation Function** | A function that applies a nonlinear transformation to a neural network layer's output. ReLU, Sigmoid, and Softmax are common activation functions. Without non-linearity, a neural network can only learn linear transformations. Activation functions are essential for capturing complex patterns. |
| **AlexNet** | The winning CNN architecture of the 2012 ImageNet competition by Alex Krizhevsky. It has 5 convolutional + 3 fully connected layers, uses ReLU activation, Dropout, and was the first major use of GPU training in deep learning, sparking the deep learning revolution. |
| **Batch Normalization** | Normalizing the activations of each mini-batch during training (mean=0, std=1). It speeds up training, allows higher learning rates, and reduces gradient vanishing/exploding problems. |
| **BGR** | The color channel order in OpenCV: Blue-Green-Red. Matplotlib and standard image formats use RGB (Red-Green-Blue). When reading an image in OpenCV, it comes in BGR format, so it must be converted to RGB before display. |
| **Binary Cross-Entropy** | The loss function for binary classification problems. It measures the difference between the true label (0/1) and the predicted probability. Perfect prediction gives loss=0, wrong predictions give high loss. Used with sigmoid output in binary classification. |
| **Canny Edge Detection** | A multi-step edge detection algorithm developed by John Canny. It follows these steps: noise reduction (Gaussian blur) → gradient calculation → non-maximum suppression → double threshold + hysteresis. Produces much cleaner results than Sobel. |
| **Channel** | The depth dimension of an image or feature map. An RGB image has 3 channels (Red, Green, Blue), grayscale has 1. In a CNN layer, output channels equal the number of filters. VGG16's first layer has 64 channels, the last has 512. |
| **Convolution** | A sliding window operation between an image and a filter/kernel. The filter slides over the image, performing element-wise multiplication and summation at each position. It is the core mechanism of feature extraction, detecting edges, textures, and patterns. |
| **Data Augmentation** | A technique to increase training data by transforming existing images (rotate, flip, zoom, shift) to create new training samples. It reduces overfitting and improves model generalization. Careful augmentation is needed for medical imaging, as flipping is not always appropriate. |
| **Dropout** | Randomly deactivating (output=0) some neurons during training. It prevents overfitting by making neurons less dependent on each other, forcing them to learn robust features. A rate of 0.5 means 50% of neurons are randomly turned off at each training step. |
| **Epoch** | One complete pass of the entire training dataset through the model. 10 epochs mean the model sees the dataset 10 times. More epochs = more training, but also increased risk of overfitting. Early stopping can automatically find the optimal number of epochs. |
| **Feature Map** | The output of a convolutional layer, representing the spatial presence of a specific feature (edge, corner, texture) in the input image. Each filter generates one feature map. Shallow layers detect simple features, while deep layers detect complex features. |
| **Filter/Kernel** | A small weight matrix (typically 3x3 or 5x5) used in convolutional layers. The filter slides over the image to extract features. Filter values are automatically learned during training, allowing the model to decide which features to detect. |
| **Fine-Tuning** | Unfreezing some layers of a pretrained model and retraining them on a new task. It is done when further improvement is needed after feature extraction. Crucially, the learning rate must be very low (1e-5) during fine-tuning, otherwise pretrained features are destroyed. |
| **Flask** | A lightweight micro web framework for Python. Ideal for ML model deployment, with minimal boilerplate, flexibility, and seamless integration with the Python ecosystem. Simpler than Django, but Django is more structured for large applications. |
| **Gradient Descent** | The optimization algorithm for neural networks. It updates weights along the direction of steepest descent of the loss function gradient. The learning rate determines how much to update: too high causes oscillation, too low causes slow convergence. |
| **ImageNet** | A massive dataset of 14M+ labeled images across 1000+ categories. It is the standard dataset for training and benchmarking deep learning models (VGG16, ResNet, AlexNet). ImageNet-pretrained weights are commonly used as a starting point in transfer learning. |
| **LeNet-5** | The first successful CNN architecture, created by Yann LeCun in 1998. It has 5 layers: 2 Conv + 2 Pool + 1 FC. Used for handwritten digit recognition (MNIST). It is the foundation of modern CNNs, introducing the convolution + pooling + fully connected pattern. |
| **Max Pooling** | A downsampling operation that reduces the size of a feature map by taking the maximum value from each window. It increases translation invariance, reduces computation, and preserves the most prominent features. Typically uses a 2x2 window with stride 2, halving the feature map. |
| **Overfitting** | When a model performs extremely well on training data but poorly on unseen data. The model memorizes the training data and loses generalization ability. Solutions: more data, data augmentation, dropout, early stopping, regularization. |
| **Padding** | Adding zeros (or other values) to the border of an image before convolution. Valid padding (no padding) produces a smaller output, while Same padding keeps the output size equal to the input. Padding is needed to preserve border information. |
| **Pooling** | An operation that reduces the spatial dimensions of a feature map, decreasing computation and increasing translation invariance. Max Pooling (max of window) and Average Pooling (average of window) are the two main types. Pooling layers sit between convolutional layers in CNN architectures. |
| **ReLU** | Rectified Linear Unit, the most popular activation function: f(x) = max(0, x). It zeros out negative values while keeping positive values unchanged. It is computationally cheap, reduces the gradient vanishing problem, and creates sparse activations, making it essential for deep network training. |
| **ResNet50** | A 50-layer deep residual network, Microsoft's 2015 architecture. Residual/skip connections solve the problem of training very deep networks by allowing gradients to flow directly to earlier layers. Achieves 3.57% top-5 error on ImageNet, approaching human-level performance. |
| **Residual Connection** | Directly adding the input of a layer to its output: output = F(x) + x. This solves the gradient vanishing problem in very deep networks by allowing gradients to reach earlier layers directly through the skip connection. ResNet's core innovation. |
| **Same Padding** | Adding padding to the input before convolution so that the output size equals the input size. A 3x3 kernel needs 1 pixel of padding, a 5x5 kernel needs 2 pixels. Output formula: output = input/stride (rounded up) with same padding. |
| **Sobel Filter** | A 3x3 convolution filter used to detect edges in an image. It has two versions: horizontal (Gx) and vertical (Gy), which detect horizontal and vertical edges separately. Also used as the first step in Canny edge detection. |
| **Stride** | How many pixels the filter jumps when moving in a convolution or pooling operation. Stride 1 = move one pixel at a time (dense output), Stride 2 = jump two pixels (output halves). Higher stride = smaller output, less computation. |
| **Transfer Learning** | Using the learned knowledge of a pretrained model for a new task. ImageNet-trained VGG16/ResNet can be used as feature extractors to train good models on small datasets. It requires much less data and time compared to training from scratch, making it the most important technique in practical ML. |
| **Underfitting** | When a model performs poorly even on training data, meaning its capacity is insufficient to learn the patterns. Solution: more layers/neurons, more epochs, complex architecture, less regularization. The opposite of overfitting. |
| **Valid Padding** | Applying convolution without any padding on the original image. The output size is smaller than the input. With a 3x3 kernel, input 32x32 → output 30x30. Some border information is lost. |
| **VGG16** | A 16-layer (weight layers) CNN architecture from Oxford's VGG group. Its key principle is using only 3x3 convolutions and 2x2 max pooling, making it simple and uniform. Has 138M parameters and achieves excellent performance on ImageNet. The most commonly used model for transfer learning. |
