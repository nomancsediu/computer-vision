## গ্লসারি

এই গ্লসারি তে কম্পিউটার ভিশন ও ডিপ লার্নিং এর গুরুত্বপূর্ণ technical terms এর Bengali definition দেওয়া হলো। Quick reference হিসেবে ব্যবহার করো  বই পড়ার সময় কোনো term মনে না এলে এখানে খুঁজে পাও।

| Term | Definition |
|------|-----------|
| **Activation Function** | Neural network layer এর output কে nonlinear transform করে এমন function। ReLU, Sigmoid, Softmax হলো common activation functions। Non-linearity ছাড়া neural network শুধু linear transformation শিখতে পারে  complex pattern capture করতে activation function অপরিহার্য। |
| **AlexNet** | 2012 সালে Alex Krizhevsky এর ImageNet competition বিজয়ী CNN architecture। 5টি convolutional + 3টি fully connected layer, ReLU activation, Dropout, ও GPU training এর প্রথম বড় ব্যবহার  deep learning revolution এর সূচনা করে। |
| **Batch Normalization** | Training এর সময় প্রতিটি mini-batch এর activation কে normalize (mean=0, std=1) করা। Training fast হয়, higher learning rate ব্যবহার করা যায়, এবং gradient vanishing/exploding problem reduce হয়। |
| **BGR** | OpenCV তে image এর color channel order: Blue-Green-Red। Matplotlib ও standard image format এ RGB (Red-Green-Red) ব্যবহার হয়। OpenCV তে image read করলে BGR আসবে  display করার আগে RGB তে convert করতে হবে। |
| **Binary Cross-Entropy** | Binary classification problem এর loss function। True label (0/1) ও predicted probability এর মধ্যে difference measure করে। Perfect prediction এ loss=0, ভুল prediction এ loss বড় হয়। Binary classification এ sigmoid output এর সাথে ব্যবহৃত। |
| **Canny Edge Detection** | John Canny এর develop করা multi-step edge detection algorithm। Noise reduction (Gaussian blur) → Gradient calculation → Non-maximum suppression → Double threshold + Hysteresis  এই steps follow করে clean edges detect করে। Sobel থেকে অনেক ভালো result দেয়। |
| **Channel** | Image বা feature map এর depth dimension। RGB image তে 3টি channel (Red, Green, Blue), grayscale তে 1টি। CNN layer এ output channels = number of filters। VGG16 এর প্রথম layer তে 64 channels, শেষে 512 channels। |
| **Convolution** | Image ও filter/kernel এর মধ্যে sliding window operation। Filter image এর উপর দিয়ে slide করে, প্রতিটি position এ element-wise multiply ও sum করে। Feature extraction এর মূল mechanism  edges, textures, patterns detect করে। |
| **Data Augmentation** | Training data বাড়ানোর technique  existing image গুলোকে transform (rotate, flip, zoom, shift) করে নতুন training sample তৈরি করা। Overfitting reduce করে, model এর generalization improve করে। Medical imaging এ careful augmentation দরকার  flip সবসময় appropriate নয়। |
| **Dropout** | Training এর সময় randomly কিছু neuron কে deactivate (output=0) করা। Overfitting prevent করে  neuron গুলো একে অপরের উপর dependent হতে পারে না, ফলে robust features শেখে। Rate 0.5 মানে 50% neuron randomly off হবে প্রতিটি training step এ। |
| **Epoch** | সম্পূর্ণ training dataset একবার model এর মধ্য দিয়ে pass হওয়া। 10 epoch মানে dataset 10 বার model দেখবে। বেশি epoch = বেশি training, কিন্তু overfitting risk ও বাড়ে। Early stopping দিয়ে optimal epoch automatically find করা যায়। |
| **Feature Map** | Convolutional layer এর output  input image এর একটি নির্দিষ্ট feature (edge, corner, texture) এর spatial representation। প্রতিটি filter একটি feature map generate করে। Shallow layer এ simple features, deep layer এ complex features detect হয়। |
| **Filter/Kernel** | Convolutional layer এ ব্যবহৃত ছোট weight matrix (সাধারণত 3×3 বা 5×5)। Filter image এর উপর slide করে feature extract করে। Training এর সময় filter values automatically learn হয়  model নিজেই decide করে কোন feature detect করবে। |
| **Fine-Tuning** | Pretrained model এর কিছু layer unfreeze করে নতুন task এর জন্য retrain করা। Feature extraction এর পর আরও improvement চাইলে fine-tuning করা হয়। অত্যন্ত গুরুত্বপূর্ণ: fine-tuning এ learning rate অনেক কম রাখতে হবে (1e-5), নাহলে pretrained features নষ্ট হয়ে যায়। |
| **Flask** | Python এর lightweight micro web framework। ML model deployment এর জন্য ideal  minimal boilerplate, flexible, Python ecosystem এর সাথে seamless integration। Django এর চেয়ে সহজ, কিন্তু large application এ Django বেশি structured। |
| **Gradient Descent** | Neural network এর optimization algorithm। Loss function কে minimize করার জন্য weights এর gradient (direction of steepest descent) বরাবর weights update করা। Learning rate নির্ধারণ করে কতটুকু update হবে  বেশি হলে oscillation, কম হলে slow convergence। |
| **ImageNet** | 14M+ labeled image এর বিশাল dataset  1000+ category। Deep learning model (VGG16, ResNet, AlexNet) এর training ও benchmark এ standard dataset। Transfer learning এ ImageNet pretrained weights কে starting point হিসেবে ব্যবহার করা হয়। |
| **LeNet-5** | Yann LeCun 1998 সালে তৈরি প্রথম successful CNN architecture। 5টি layer  2 Conv + 2 Pool + 1 FC। Handwritten digit recognition (MNIST) এ ব্যবহৃত। Modern CNN এর foundation  convolution + pooling + fully connected pattern এখান থেকেই শুরু। |
| **Max Pooling** | Feature map কে ছোট করার downsampling operation  প্রতিটি window এর maximum value নেওয়া হয়। Translation invariance বাড়ায়, computation reduce করে, এবং সবচেয়ে prominent feature preserve করে। সাধারণত 2×2 window, stride 2 ব্যবহৃত  feature map অর্ধেক হয়। |
| **Overfitting** | Model training data তে অত্যন্ত ভালো performance দেয় কিন্তু নতুন unseen data তে poor performance দেয়। Model training data memorize করে ফেলে  generalization ability হারায়। Solution: more data, data augmentation, dropout, early stopping, regularization। |
| **Padding** | Convolution operation এর আগে image এর border এ zeros (বা অন্য value) যোগ করা। Valid padding (no padding) এ output ছোট হয়, Same padding এ output ও input same size হয়। Border information preserve করার জন্য padding দরকার। |
| **Pooling** | Feature map এর spatial dimension কমানোর operation  computation reduce ও translation invariance বাড়ায়। Max Pooling (window এর max) ও Average Pooling (window এর average) দুটি main type। CNN architecture এ pooling layer convolutional layer এর মধ্যে থাকে। |
| **ReLU** | Rectified Linear Unit  সবচেয়ে popular activation function: f(x) = max(0, x)। Negative values কে 0 করে, positive values unchanged রাখে। Computation cheap, gradient vanishing problem reduce করে, এবং sparse activation তৈরি করে  deep network training এ অপরিহার্য। |
| **ResNet50** | 50-layer deep residual network  Microsoft এর 2015 সালের architecture। Residual/Skip connection দিয়ে very deep network train করার সমস্যা solve করে  gradient directly earlier layer এ flow করতে পারে। ImageNet এ 3.57% top-5 error  human level performance! |
| **Residual Connection** | Layer এর output এ সেই layer এর input সরাসরি যোগ করা: output = F(x) + x। Very deep network এ gradient vanishing problem solve করে  gradient skip connection দিয়ে earlier layer এ সরাসরি পৌঁছাতে পারে। ResNet এর core innovation। |
| **Same Padding** | Convolution এর আগে input এ padding যোগ করা যাতে output size ও input size same হয়। 3×3 kernel এর জন্য 1 pixel padding দরকার, 5×5 kernel এ 2 pixel। Output size formula: same padding এ output = input/stride (round up)। |
| **Sobel Filter** | Image থেকে edges detect করার জন্য ব্যবহৃত 3×3 convolution filter। Horizontal (Gx) ও Vertical (Gy)  দুটি version আছে। Horizontal edges, vertical edges আলাদাভাবে detect করে। Canny edge detection এর প্রথম step হিসেবে ও ব্যবহৃত। |
| **Stride** | Convolution বা pooling operation এ filter কত pixel jump করে move করবে। Stride 1 = এক pixel করে move (dense output), Stride 2 = দুই pixel করে jump (output অর্ধেক)। বেশি stride = ছোট output, কম computation। |
| **Transfer Learning** | Pretrained model এর learned knowledge নতুন task এ ব্যবহার করা। ImageNet trained VGG16/ResNet কে feature extractor হিসেবে ব্যবহার করে ছোট dataset এ ভালো model train করা যায়। Scratch training এর তুলনায় অনেক কম data ও time লাগে  practical ML এর সবচেয়ে important technique। |
| **Underfitting** | Model training data তেই poor performance দেয়  মানে model এর capacity কম, pattern শিখতে পারছে না। Solution: বেশি layer/neuron, বেশি epoch train, complex architecture, less regularization। Overfitting এর বিপরীত সমস্যা। |
| **Valid Padding** | Convolution এ কোনো padding যোগ না করা  original image তেই convolution apply হয়। Output size input থেকে ছোট হয়। 3×3 kernel এ input 32×32 → output 30×30। Border information কিছুটা হারায়। |
| **VGG16** | Oxford এর VGG group এর 16-layer (weight layer) CNN architecture। Key principle: শুধু 3×3 convolution ও 2×2 max pooling ব্যবহার  simple ও uniform architecture। 138M parameters, ImageNet এ excellent performance। Transfer learning এ সবচেয়ে বেশি ব্যবহৃত model। |
