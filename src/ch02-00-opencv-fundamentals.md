# OpenCV ফান্ডামেন্টালস

এই চ্যাপ্টারে আমরা OpenCV দিয়ে ইমেজ রিডিং, প্রসেসিং, রিসাইজিং, ক্রপিং, শেইপ ড্রয়িং, পারস্পেক্টিভ ট্রান্সফরমেশন এবং ইমেজ জয়েনিং শিখবো। OpenCV হলো কম্পিউটার ভিশন এর সবচেয়ে জনপ্রিয় লাইব্রেরি।

OpenCV (Open Source Computer Vision Library) হলো একটি open-source লাইব্রেরি যা ১৯৯৯ সালে Intel এর গ্যারি ব্র্যাডস্কি তৈরি করেছিলেন। এরপর থেকে এটি কম্পিউটার ভিশন এবং মেশিন লার্নিং এর জগতে একটি অপরিহার্য টুলে পরিণত হয়েছে। ফেস ডিটেকশন, অবজেক্ট ট্র্যাকিং, অপটিক্যাল ক্যারেক্টার রিকগনিশন (OCR) — সবকিছুর পেছনেই OpenCV এর ব্যবহার আছে। এটি C++, Python, Java সহ বিভিন্ন ভাষায় ব্যবহার করা যায়, তবে Python এ সবচেয়ে সহজে কাজ করা যায় বলে আমরা সেটাই ব্যবহার করবো।

এই চ্যাপ্টারে আমরা ধাপে ধাপে শিখবো কিভাবে একটি ইমেজ লোড করতে হয়, কিভাবে সেটাকে প্রসেস করতে হয়, এবং কিভাবে ফলাফল দেখতে হয়। প্রতিটি টপিকে আমরা বাস্তব কোড উদাহরণ দেখবো যাতে তুমি সহজে নিজে প্র্যাকটিস করতে পারো। চলো, শুরু করা যাক!
